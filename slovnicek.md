# Slovníček — závazná terminologie webu

Platí pro všechny texty na openwork.cz i openwork.sk (tam ve slovenštině
se stejnou logikou). Levý sloupec se na webu nepoužívá, pravý ano.

| Nepoužívat | Používat |
|---|---|
| provider | poskytovatel |
| free tier | bezplatná úroveň |
| pay-as-you-go | platba za spotřebu |
| shared billing | společná peněženka |
| API key | klíč (při prvním výskytu „klíč — přístupové heslo pro aplikace") |
| local inference, on-device | běh na vlastním počítači |
| cloud (jako sloveso „dát do cloudu") | uložit na cizí server |
| workspace | pracovní prostor / složka |
| settings | nastavení |
| feature | funkce |
| subscription | předplatné |
| prompt | zadání / pokyn |
| open-weight model | otevřený model (při prvním výskytu vysvětlit: „model, který si můžete stáhnout a provozovat sami") |
| fine-tuning | doladění modelu |
| deploy | nasadit |
| self-hosting | provoz na vlastním serveru |
| suverenita, digitální suverenita | data pod vaší kontrolou / nezávislost na velkých platformách (slovo „suverenita" na webu nepoužíváme vůbec) |
| lokálně | na vlastním počítači |
| inference | výpočet (při prvním výskytu: „výpočet — když model zpracovává vaše zadání") |

## Zůstává v originále (s vysvětlením při prvním výskytu na stránce)

- **OpenWork** — aplikace, o které web je
- **opencode** — motor, na kterém OpenWork staví (zmiňovat jen na stránce o ekosystému)
- **OpenCode Zen**, **OpenCode Go** — brány k modelům od tvůrců opencode. **Vždy plným názvem „OpenCode Go" / „OpenCode Zen", nikdy jen „Go" / „Zen".** OpenCode Go referral odkaz: https://opencode.ai/go?ref=K0VC03J925 (použít jako CTA „začít")
- **Cortecs** — evropská brána k modelům
- **MCP** — způsob, jak agent připojuje další služby
- **ZDR** — rozepsat: „nulové uchovávání dat (zero data retention)"
- **AGENTS.md** — soubor s pravidly pro agenta
- **token** — vysvětlit: „kousek textu, po kterých se počítá spotřeba"
- **GDPR**, **NIS2**, **Astro**, názvy modelů (GLM, Qwen, Llama…)

## Tón

- „vy" s malým v, přátelsky, bez podbízení
- čísla s mezerou (10 000), ceny s měnou za číslem (250 Kč, 10 $ měsíčně)
- datum ve tvaru 30. srpna 2026
