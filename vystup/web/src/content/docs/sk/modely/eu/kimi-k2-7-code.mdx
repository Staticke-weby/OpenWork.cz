**Kimi K2.7 Code** je otvorený model od čínskej firmy **Moonshot AI**,
vyladený na **programovanie**. V OpenWorku sa hodí, keď chcete, aby agent
napísal skript, upravil web alebo automatizoval opakovanú prácu. V Európe
ho prevádzkujú Melious a Cortecs, takže kód aj dáta zostanú v EÚ.

<ModelKarta slug="kimi-k2-7-code" />

## Na čo sa hodí

- **Skripty a automatizácia** — prevody súborov, hromadné premenovanie,
  spracovanie tabuliek.
- **Weby a malé aplikácie** — agent ich napíše aj upraví.
- **Opravy chýb** — prečíta aj snímku obrazovky s chybovým hlásením.

## Kde ho vezmete

<ModelNabidky slug="kimi-k2-7-code" />

**Kde ho vziať:** u [Melious](/sk/modely/poskytovatele/melious/) alebo [Cortecs](/sk/modely/poskytovatele/cortecs/) — obe európske brány odporúčame
rovnako; u Cortecs je o niečo lacnejší.
