V štúdiu agent najviac pomôže s tým, čo žerie čas okolo učenia: **prepísať,
utriediť, vyskúšať, ustrážiť termíny.** Učenie samotné za vás neurobí — ale
urobí z neho oveľa efektívnejšiu prácu: z kopy slajdov budú výpisky za
minúty a namiesto pasívneho čítania vás agent aktívne vyskúša.

## Typické situácie

- **Pred skúškou** — výpisky z prednášok, otázky na skúšanie, plán
  opakovania podľa termínov.
- **Pri písaní práce** — utriedenie zdrojov, osnova, kontrola štruktúry
  a citácií; text píšete sami.
- **Počas semestra** — termíny odovzdania a skúšok zo všetkých predmetov
  na jednom mieste.

## Tri zásady poctivého štúdia s AI

1. **Agent pripravuje podklady, prácu píšete sami.** Školy vygenerovaný
   text spoznajú — a hlavne: čo neprejde vašou hlavou, to sa nenaučíte.
2. **Pri každom tvrdení zdroj.** Výpisky s označením, z ktorého materiálu
   pochádzajú — kvôli citáciám aj kontrole, že si agent nevymýšľa.
3. **Skúšať sa, nie len čítať.** Aktívne vybavovanie je najúčinnejší
   spôsob učenia — a agent je neúnavný skúšajúci.
