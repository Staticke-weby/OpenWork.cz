**Kimi K2.7 Code** je otevřený model od čínské firmy **Moonshot AI**,
vyladěný na **programování**. V OpenWorku se hodí, když chcete, aby agent
napsal skript, upravil web nebo automatizoval opakovanou práci. V Evropě
ho provozují Melious a Cortecs, takže kód a data zůstanou v EU.

<ModelKarta slug="kimi-k2-7-code" />

## K čemu se hodí

- **Skripty a automatizace** — převody souborů, hromadné přejmenování,
  zpracování tabulek.
- **Weby a malé aplikace** — agent je napíše i upraví.
- **Opravy chyb** — přečte i snímek obrazovky s chybovou hláškou.

## Na co si dát pozor

- **Na běžné texty je zbytečně drahý.** Pro e-maily a shrnutí stačí
  [DeepSeek V4.1 Flash](/modely/eu/deepseek-v4-1-flash/).
- **Na nejtěžší úlohy** existuje silnější [Kimi K3](/modely/eu/kimi-k3/) —
  ale je zhruba čtyřikrát až pětkrát dražší.

## Kde ho vezmete

<ModelNabidky slug="kimi-k2-7-code" />

**Naše volba:** [Melious](/modely/poskytovatele/melious/) — nic neukládá
bez nastavování. O něco levněji ho má [Cortecs](/modely/poskytovatele/cortecs/).
