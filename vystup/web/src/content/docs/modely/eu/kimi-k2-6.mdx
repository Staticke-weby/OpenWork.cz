**Kimi K2.6** je otevřený model od čínské firmy **Moonshot AI**. Je to
univerzálnější sourozenec programovacího [Kimi K2.7 Code](/modely/eu/kimi-k2-7-code/)
— hodí se na delší úkoly, kde agent postupuje po krocích.

<ModelKarta slug="kimi-k2-6" />

## K čemu se hodí

- **Delší úkoly o více krocích** — agent postupně projde složku, něco
  vyhledá, něco přepíše.
- **Obrázky** — přečte fotky a snímky obrazovky.

## Kde ho vezmete

<ModelNabidky slug="kimi-k2-6" />

**Kde ho vzít:** u [Melious](/modely/poskytovatele/melious/) nebo [Cortecs](/modely/poskytovatele/cortecs/) — obě evropské brány doporučujeme
stejně; u Cortecs je levnější.
