Agent pracuje líp, když má **přehledně uspořádanou složku**. Nemusíte nic
složitého — stačí pár rozumných návyků.

## Pár zásad

- **Jedna složka = jeden úkol nebo projekt.** Nemíchejte nesouvisející věci
  dohromady.
- **Pracujte na kopii.** U důležitých souborů si udělejte kopii, ať máte klid,
  kdyby něco nevyšlo napoprvé.
- **Podklady zvlášť.** Vstupní dokumenty, výstupy a pravidla držte v přehledných
  podsložkách.

## Ukázka uspořádání

Takhle může vypadat složka pro jeden úkol:

- **muj-projekt/**
  - `AGENTS.md` — pravidla pro agenta ([viz samostatná stránka](/prace-se-slozkou/agents-md/))
  - **podklady/** — vstupní dokumenty, ze kterých agent čerpá
  - **vystup/** — sem agent ukládá výsledky
  - `poznamky.md` — vaše poznámky k úkolu

Nic z toho není povinné — je to jen vzor, který se osvědčuje. Klidně si ho
upravte podle sebe.

## Proč na tom záleží

Když má agent jasno, kde co je, méně tápe a míň se ptá. A vy máte přehled, co je
vstup a co výsledek.
