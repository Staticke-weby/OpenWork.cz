Na tomto webu píšeme pro obyčejné lidi. Kde jde technický výraz nahradit
českým, nahrazujeme ho. Tady je přehled, co které slovo znamená.

## Místo cizích slov říkáme

| Cizí výraz | Říkáme |
|---|---|
| provider | poskytovatel |
| free tier | bezplatná úroveň |
| pay-as-you-go | platba za spotřebu |
| shared billing | společná peněženka |
| API key | klíč (přístupové heslo pro aplikace) |
| local inference, on-device | běh na vlastním počítači |
| cloud (dát do cloudu) | uložit na cizí server |
| workspace | pracovní prostor / složka |
| settings | nastavení |
| feature | funkce |
| subscription | předplatné |
| prompt | zadání / pokyn |
| open-weight model | otevřený model (model, který si můžete stáhnout a provozovat sami) |
| fine-tuning | doladění modelu |
| deploy | nasadit |
| self-hosting | provoz na vlastním serveru |
| inference | výpočet (když model zpracovává vaše zadání) |

## Slova, která necháváme v originále

Tyto názvy nemá smysl překládat — jen je jednou vysvětlíme.

- **OpenWork** — aplikace, o které tento web je.
- **opencode** — motor, na kterém OpenWork staví.
- **Zen**, **Go** — brány k modelům od tvůrců opencode.
- **Cortecs** — evropská brána k modelům.
- **MCP** — způsob, jak agent připojuje další služby.
- **ZDR** — nulové uchovávání dat (zero data retention).
- **AGENTS.md** — soubor s pravidly pro agenta.
- **token** — kousek textu, po kterých se počítá spotřeba.
- **GDPR**, **NIS2**, **Astro** a názvy modelů (GLM, Qwen, Llama…) zůstávají také v originále.
